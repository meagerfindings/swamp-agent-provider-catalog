# swamp-agent-provider-catalog

[swamp](https://swamp.club) extension `@mgreten/agent-provider-catalog` — a
caller-supplied provider/model catalog with conservative tiered fallback and
dispatch resolution for agent-dispatch pipelines.

📖 **Extension documentation:** [extensions/models/README.md](extensions/models/README.md)

📦 **Install:** `swamp extension pull @mgreten/agent-provider-catalog`

## Repository layout

This repository is a swamp workspace (its own `.swamp.yaml` repo). The
publishable extension lives under [extensions/models/](extensions/models/).
